Executable behavior specifications

Describe behavior.
Check the code.

LawSpec turns expected behavior into executable checks. Write examples, properties and reference models, run them against an implementation, and inspect what the resulting evidence establishes.

Learn LawSpec ↗ Read the documentation ↗

Start with a small, runnable example.

The learning track begins with F# and builds up examples, properties and shrinking. Change the code, run the checks, and use counterexamples to understand where the behavior differs from your expectations. 

npm install --global lawspec
lawspec learn
